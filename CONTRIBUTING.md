# Contribuindo

## Estrategia de branches

- `main`: branch estavel e protegida.
- `feat/*`: novas funcionalidades.
- `fix/*`: correcao de bugs.
- `chore/*`: manutencao e tarefas internas.

## Regras de trabalho

1. Crie branch a partir da `main`.
2. Faça commits pequenos e objetivos.
3. Abra Pull Request para merge na `main`.
4. Aguarde CI verde e ao menos 1 aprovacao.

## Convencao de commits

- `feat:`
- `fix:`
- `refactor:`
- `docs:`
- `chore:`

Exemplo:

`feat: add responsive project cards section`
